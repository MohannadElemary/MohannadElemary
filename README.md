## About me

I design, build, and operate backend systems across **financial services, e-commerce, and consumer products**. I've worked on systems serving **100M+ monthly active users**, with experience spanning APIs, data processing, integrations, and production operations.

My approach to software architecture focuses on clear domain boundaries, maintainable services, and reliable data flows. I work with concepts from **domain-driven design, event-driven architecture, and hexagonal architecture**, applying patterns where they help manage complexity.
